# 华为云前端部署与 Supabase 接入

前端在哪里托管与 Supabase 在哪里运行分别选择。浏览器加载前端后直接调用已有 Supabase HTTPS API；终端用户无需华为云账号。保留已有框架、环境和发布方式，不新增独立部署 CLI。

## 选择路线

先读取项目、会话及已有环境记录；更新/回退沿用已绑定路线，不重新选择平台。无明确选择且缺少域名时，询问是准备域名、选择 ECS 公网 IP，还是使用其他平台默认域名；等待期间可完成本地构建。

| 条件 | 行为与必读指引 |
| --- | --- |
| 已在其他平台托管 | 优先保留项目、域名与 CI，仅接入后端或按请求更新；读 [其他平台](references/external-hosting.md)。 |
| 选择华为云，已有可用域名 | 默认私有 OBS＋CDN；读 [域名与托管](references/hosting.md) 及 [OBS 发布](references/obs-release.md)。 |
| 选择华为云，准备办理域名 | 先本地构建与预览，域名、证书及适用备案条件齐备后继续 OBS/CDN；不报告公网完成。 |
| 明确选择 ECS，或选择华为云且明确不准备域名、要求公网 IP 访问 | 复用或按授权创建 ECS＋EIP＋Nginx；读 [ECS 发布](references/ecs-hosting.md)。缺少域名本身不授权购买。 |
| 尚未托管，接受其他平台默认域名 | 优先已有账号/平台偏好；无法确定时让用户选择 Cloudflare Pages 或 Vercel，按 [其他平台](references/external-hosting.md) 创建及发布。 |

## 任务与工作流

1. **确定范围。** 区分准备环境、创建并部署、只接入 Supabase、更新、回退。只接入后端不隐含迁移前端或采购资源；仅有访问 URL 而无源码/发布权限时完成只读诊断并列出缺项，不宣称已改造应用。
2. **检查应用。** 创建/修改应用时读 [前端构建](references/frameworks.md)。新项目未指定时使用 React＋Vite＋TypeScript；Vue、普通静态网站和已有静态导出沿用原方案。SSR、服务端 API、运行时秘密需求单独说明，选择 ECS 也不自动授权部署后端。
3. **核实所需环境。** 仅在查询/管理华为云资源时读 [认证](references/authentication.md) 和 [区域](references/regions.md)。第三方前端已有 Supabase HTTPS URL/公开 Key 时可直接检查接入，不强制配置华为云 CLI。各平台按对应指引核实账号归属、资源、部署权限、费用和已有记录。
4. **接入已有 Supabase。** 需要后端时读 [Supabase](references/supabase.md)，配置公开连接参数、真实 origin、回调、CORS 和 RLS。先取得真实稳定入口；新平台尚无入口时先创建项目或无登录的预览，再配置回调并重新构建。没有安全可用的后端地址时，不扩张网络权限来掩盖缺项。
5. **构建并发布。** 按选中路线准备具体请求、资源/配置差异、费用和恢复点；在已有授权内执行。新付费资源、授权外公网/数据库变更才需确认；首次登录、MFA、域名实名及备案由用户完成。准备环境请求以检查与计划为交付，除非已授权，否则不发布生产。
6. **验证与记录。** 所有路线读 [通用发布记录与验收](references/deployment.md)。先校验产物再切换入口，用真实访问地址验收，失败按对应路线恢复。只在适用检查通过后记录成功版本。

## 工具与边界

华为云资源优先 KooCLI，OBS 文件用内置 OBS 工具或 obsutil；ECS 通过已核实身份的 SSH 管理；其他平台优先已有连接器、官方 CLI 或既有 CI。执行前核对本地帮助和当前官方 schema；工具缺失说明缺口，不自建签名器或调用未公开接口。

查询分页完成才判定资源不存在。认证/权限/参数错误修正前停止重试；瞬时读取最多重试三次。异步创建或发布结果不明先查询任务及资源，不能盲目重复购买或发布；等待默认最多 30 分钟，超时记录 ID 供续跑。保留共享配置，不因缺域名、无配额或区域限制自动换路线、换区或购买数据库。

## 交付

报告路线、修改、产物、实际访问 URL（注明 HTTP/HTTPS、预览/生产）、当前及前一成功版本、验收与恢复结果、费用假设和阻碍。明确区分 **skill 已完成 / 本地应用已验证 / 环境已准备 / 线上验收通过**；HTTP 页面可达不等于 HTTPS/Auth 通过。来源与实测边界见 [官方资料](references/sources.md)。

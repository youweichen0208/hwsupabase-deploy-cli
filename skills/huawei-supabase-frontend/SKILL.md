# 华为云前端部署与 Supabase 接入

默认架构为静态前端 → 自有域名的 HTTPS CDN → 私有 OBS 产物桶；浏览器直接访问已有 Supabase HTTPS API。终端用户无需登录华为云，应用身份由 Supabase Auth 管理。不新增独立部署 CLI。

## 任务入口

四种任务共用项目的 `.hwsupabase/frontend/<环境>/` 记录，结构见 [发布与回退](references/deployment.md)。读取已有记录后查询实际资源，记录本身不授予操作权限。

| 用户任务 | 执行范围与完成条件 |
| --- | --- |
| 准备环境 | 验证认证、发现已有 Supabase、检查域名/证书/OBS/CDN，交付资源和费用计划；仅执行范围内已授权的配置。 |
| 创建并部署前端 | 识别或创建项目、配置公开连接参数、构建、发布并验证真实入口。 |
| 更新应用 | 复用环境和上一个成功版本，构建并发布差量内容及必要配置变更。 |
| 回退应用 | 选择指定的已验证版本，恢复入口和相关配置，刷新缓存并重新验收。 |

## 工作流

1. **识别应用与任务。** 读取项目说明、锁文件、构建配置及环境记录。创建/更新时阅读 [前端构建](references/frameworks.md)；已有项目沿用框架，新项目未指定时用 React＋Vite＋TypeScript。检测服务端依赖，明确静态部署能覆盖的范围。
2. **核实环境。** 准备云环境或执行发布/回退时阅读 [认证](references/authentication.md) 和 [区域](references/regions.md)。先做只读查询，区分不存在、无权限、未完成查询；自动解析可确定的名称与 ID，仅对无法消歧的信息询问。
3. **连接已有后端。** 需要 Supabase 时阅读 [Supabase 接入](references/supabase.md)。默认复用已有应用；浏览器只使用 Publishable Key 或已有 Anon Key。后端公网、迁移、RLS 修改按各自授权范围执行。
4. **准备真实入口。** 阅读 [域名、私有桶与 CDN](references/hosting.md)，产出具体请求、资源差异、委托权限范围和费用估算。复用已有授权；超出范围的新增付费资源或公开访问变更才需确认。域名注册、实名认证、备案及首次凭证登录由用户完成。缺少域名时继续本地构建和预览，交付产物及缺项，不报告公网部署成功。
5. **发布或恢复。** 阅读 [发布与回退](references/deployment.md)，先校验版本资源，再切换入口，刷新相关缓存。仅在全部适用验收通过后更新成功版本。无部署请求时完成本地交付即可。

## 工具与边界

优先 KooCLI 管理资源，OBS 文件操作使用内置 OBS 工具或官方 obsutil。操作前以本地帮助及当前官方 schema 核实参数；不编写签名器或抓取未公开接口。工具缺失不等于服务不支持，说明缺口后采用官方工具/控制台路径。

认证、权限和参数错误修正前停止重试；瞬时读取失败最多重试三次。创建请求结果不明先查询对账，避免重复创建。保留已有配置和共享资源；缺少域名、备案或服务能力不触发购买服务器、数据库或自动切换地区。

## 交付

逐项报告 **skill 已完成 / 本地应用已验证 / 环境已准备 / 线上验收通过** 的实际状态及未执行原因。应用任务还需报告产物、资源 ID、真实 URL、当前及前一成功版本、缓存任务状态、费用假设与回退方式。参考 [官方资料](references/sources.md) 核实能力，不把文档检查或 API 成功响应当作真实部署验收。

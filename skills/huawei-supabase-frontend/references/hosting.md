# 域名、私有 OBS 与 CDN

## 入口前置条件

用户使用 `https://app.example.com`，DNS 指向 CDN 实际返回的 CNAME；CDN 终止客户端 TLS 并回源私有 OBS，浏览器另行访问 Supabase HTTPS API。用户登录应用使用 Supabase Auth，无需华为云账号。

先读取已有域名、证书、桶和 CDN 记录，查询所有权、配置与状态。没有域名时交付本地预览、构建产物和上线清单；OBS 默认域名可能强制下载网页文件，不能充当可靠的正式入口。域名注册/选择、实名认证及备案由用户完成，不代替用户作身份声明。

中国大陆及全球 CDN 加速范围需域名备案。首次通过华为云备案还涉及可备案资源条件，按当前官方规则检查；不能承诺仅买域名即可上线或没有其他资源成本。不因备案缺项自动购买服务器或改到境外。证书检查覆盖域名、有效期、证书链及续期安排；私钥通过官方安全配置交互处理，不写入部署记录。

依据：[OBS 在线预览约束](https://support.huaweicloud.com/usermanual-obs/obs_03_0342.html)、[备案条件](https://support.huaweicloud.com/icprb-icp/icp_01_0008.html)。

## 资源计划与配置顺序

1. 优先复用本项目专用前端桶；新桶明确 region、名称、存储类别、企业项目和保留策略。保持私有，不开启公共网站模式，不混用 Supabase 用户上传文件桶。查询失败不作为创建理由。
2. 查询 CDN 已有域名与完整配置，使用官方私有 OBS 源站模式及官方委托。配置前记录委托名称、授权对象、策略、资源范围和本次差异；官方 `CDNAccessPrivateOBS` 可能涵盖账号下私有桶，不能声称只授权单桶。先核实可用的最小范围；若必须扩大权限，将实际范围纳入变更及授权，不擅自修改共享委托。
3. 从桶实际属性取得源站地址，检查 CDN 私有桶访问开关、回源 Host、回源协议和 TLS 匹配。沿用私有对象源站，避免误启用 `obs_web_hosting_status`。先验证 CDN 能读取指定对象，同时匿名直连私有桶不可读取；私有源站并不让 CDN 上的前端文件保密。
4. 配置域名 HTTPS、证书、HTTP 到 HTTPS 跳转、下述路径和缓存规则。修改前保存脱敏配置快照，仅合并必要字段，不覆盖共享配置。
5. 读取 CDN 返回的域名 ID、实际 CNAME 和运行状态，再在有权限的 DNS 提供商配置对应记录。先检查现有解析、冲突和 TTL，保留无关记录；不拼接 CNAME，不用未经验证的 apex CNAME。第三方 DNS 不可操作时提供精确记录给用户。
6. 等待 CDN 配置与 DNS 生效，有限等待并记录最后状态；默认最多 30 分钟，每次查询间隔 15–30 秒。超时下次从查询恢复，不重复创建资源。真实浏览器域名验收通过才算入口就绪，手改 Host 或 `curl --resolve` 仅用于诊断。

管理操作优先 `hcloud CDN --help`、`hcloud DNS --help` 发现命令；OBS 优先内置工具或 obsutil。查询/修改的 JSON schema 从当前命令帮助或 API Explorer 取得，不自行猜测字段。请求文件也可能含证书等秘密，使用临时受限文件且不纳入版本记录。

依据：[私有桶接入及委托](https://support.huaweicloud.com/usermanual-obs/obs_03_0600.html)、[CDN 配置入口](https://support.huaweicloud.com/usermanual-cdn/cdn_01_0001.html)。

## 首页与 SPA 页面路由

由实际前端路由生成匹配规则：`/` 精确改写为 `/index.html`；`/login`、`/auth/callback` 等明确页面及限定的动态页面规则内部改写到入口。保留原浏览器路径与登录回调查询参数，避免重定向丢失会话参数。静态多页站点按导出映射匹配各 HTML。

资源与 API 命名空间优先排除，未知 `/api/...` 和缺失 JS/CSS 保持 4xx（私有 OBS 可能返回 403），正文不能是首页。不要配置全域 403/404 转首页，也不要以不含点号作为唯一页面规则。检查规则优先级、实际正则支持及是否误匹配资源；能力不足时报告具体阻碍，不静默更换路由模式。

可以选择 CDN 的访问 URL 内部改写或回源 URL 改写，按当前能力确认缓存键和规则执行顺序，不叠加未经验证的两套改写。访问改写可能共用入口缓存键，回源改写可能保留各页面缓存键；发布时据实刷新所有受影响路径。验证首页、深层刷新、带查询的回调、缺失资源和未知 API。

依据：[访问 URL 重写](https://support.huaweicloud.com/usermanual-cdn/cdn_01_0263.html)。

## 预算与告警

前端侧以约 300 元/月为规划目标，按当前站点价格及查询日期列出用量假设：OBS 容量、请求数、回源流量、CDN 下行流量/峰值带宽与计费模式、日志存储、域名年费折月、证书或 DNS 的适用费用。计算低/预期/高流量情景，避免重复计算免费或套餐覆盖部分；价格未知时明确未知，不给出虚构报价。

Supabase 实例、存储、公网带宽及其他后端费用独立列出。备案所需资源若缺失也独立说明。已有授权且产品支持时设置费用预算告警、流量/带宽告警并验证通知对象；可建议 50%、80%、100% 阈值，发送测试通知仍需对应授权。记录无法配置的告警及人工路径。预算与告警不是账单硬上限，也不默认触发停站或删除资源。

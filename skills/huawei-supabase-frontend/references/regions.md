# 区域名称与 region ID

核实日期：2026-11-06。此表缓存官方区域名称和 ID，供自然语言输入优先本地匹配；不是 OBS/RDS 的服务可用区域清单。部署前仍需查询目标服务和账号可用性。project ID 属于账号，不能写成公共映射。

## 匹配规则

1. 用户提供完整 region ID 时保留该 ID；不在表内不等于无效，查官方资料核实后继续。
2. 中文区域名称先在下表匹配。可忽略空格及连字符样式，将同一名称中的数字写法归一，例如“北京4”“北京四”“华北北京四”对应同一条目。保留城市后的编号以及“汽车”“友好用户环境”“OP5”等限定词。
3. 下表常用简称仅是本 skill 的输入别名，官方对应关系以“官方名称”列为准。英文输入先按官方英文显示名称核实，不能把不确定的翻译加成别名。
4. “北京”“上海”“乌兰察布”“墨西哥城”等未指明编号的输入不能任意选一项。已有明确的同一部署目标配置可用来消歧；否则展示候选并询问一次。“华北”“华东”“亚太”等大范围描述也不足以唯一选区。
5. 普通“广州”按标准广州区域匹配，只有明确提及“友好用户环境”才使用特殊区域；汽车、联盟或其他专用区域也必须保留其使用条件。不得因为标准区域无库存而切换到特殊区域。
6. “华东二”是 cn-east-4，“上海二”是 cn-east-2；“华北三”是 cn-north-12。地区名称中的序号不一定等于 ID 后缀，必须查表，不能拼接推算。
7. 未命中、官方信息冲突、区域更名或服务报告区域不存在时，查询官方区域/终端节点资料或本地 KooCLI 支持的区域查询能力。查到唯一对应后继续，无法确定才询问；不得以网络或认证错误为理由换区域。

## 中国站与国际站

两站共用下面的区域名称映射，不把中国站等同于中国境内，也不把国际站等同于海外区域。保留当前凭证对应的账号上下文；不能从 AK 字符串、region ID 或本机语言猜测站点，不能为消除错误自动切换账号/站点。

保留中国站和国际站的区域名称解析；账号站点、OBS 桶所在区域、RDS 应用所在区域和 CDN 加速范围分别核实。CDN 的中国大陆/境外/全球是加速范围，不是 OBS region ID。使用对应站点的官方终端节点目录检查 OBS、RDS 实际能力；仅有 IAM 区域名称并不代表能创建这些服务。

## 运行时不支持的处理

名称解析与服务能力检查分开进行，静态映射不作为拒绝列表。表内外明确的目标区域均先按官方能力和只读查询核实；未知名称查官方映射，无法唯一解析再询问。完成查询后若区域/局点不支持 OBS、RDS Supabase 或所需 CDN 功能，正常提示具体缺项并停止该依赖的创建，不自动换区、不反复购买。

保留服务错误码及脱敏说明，区分以下结果：

- 明确不支持：说明账号上下文、区域和不支持的服务/功能；可列经核实的替代区域供用户选择。
- 401/403：说明认证或权限问题，不能断言区域不支持。
- 配额、库存或账户条件限制：如实提示对应原因，不能升级规格或更换站点绕过。
- 网络超时或查询不完整：说明暂时无法核实，不标记永久不支持。

分别核实 OBS 桶区域、已有 RDS Supabase 应用可用性及 CDN 回源/加速范围；跨区访问还要评估延迟和费用。仅在对应 API 需要时解析账号项目 ID。账号站点影响报价而无法从上下文确定时再询问。依据：[中国站与国际站差异](https://support.huaweicloud.com/usermanual-account/account_id_015.html)。

## 用法与维护

- “帮我部署到北京四” → cn-north-4，再交给 KooCLI 解析账号下的项目。
- “上海2区” → 若上下文明确指区域则为 cn-east-2；若指可用区 AZ，则需先确定 region，再查询 AZ，不把 AZ 当区域。
- “部署到北京” → 结合已有目标消歧，否则列出北京一/二/四。
- “广州友好用户环境” → cn-south-4，之后核实账号与目标服务是否支持。

此表不是穷尽列表。新增条目必须由官方名称/ID 对确认，记录来源和核实日期；只读部署过程遇到新信息可在当前任务使用，用户要求维护 skill 时再更新文件。已确认的区域解析结果在同一次任务中复用，无需为同一名称反复联网。

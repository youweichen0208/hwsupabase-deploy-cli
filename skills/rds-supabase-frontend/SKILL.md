# 华为云前端部署与 Supabase 接入

前端静态产物存放在公开读 OBS 桶，通过自有域名的两条托管路线之一提供访问：`obs-domain`（入口域名直连桶，默认）或 `obs-cdn`（入口域名经 CDN 回源同一公开桶）。浏览器加载前端后直接调用已有华为云 RDS Supabase HTTPS API，终端用户无需华为云账号。保留已有框架、构建环境和 OBS 发布方式，不新增独立部署 CLI。

## 先快照，再读取分支

先单批并行完成独立只读检查：项目 `.hwsupabase` 记录、`~/.obsutilconfig` 的 endpoint（只提取端点，凭据不输出）、已有产物清单与哈希、已知入口候选 GET；有目标桶后并行查询对象清单、website、域名及桶策略。无目标桶才用 `hcloud obs ls` 发现。依赖前一步结果的查询另批执行。由快照确定区域、桶、路线和本次差异；与已有记录一致的状态本轮不重复验证，切换前并发发布校验除外。完成快照后只读取本次分支所需 references。

endpoint 或 console 主机以 `.ulanqab.huawei.com` 结尾时读取 [内部云](references/internal-cloud.md)，区域沿用 endpoint 与既有记录；冲突才询问用户。首次接触默认域名即说明可能强制下载，快照后立即索要真实入口域名，同时推进已授权的构建和候选上传。候选上传不代表稳定入口验收通过。

## 重复发布快速路径

已有成功记录、同桶新版本或切回已验收原产物、无托管配置变更且本次操作已获授权时，沿用未变更的策略、website、域名结论，不再进入确认清单。先核对产物哈希和本次对象键被既有策略覆盖，再单遍上传 → 一轮批量 GET → 写新记录 → 报告。生产切换若已获本次授权不重复确认；历史成功记录本身不授予新操作权限。配置漂移、策略不覆盖或产物不一致时退出快速路径，仅处理差异。

基础必检为 `entry`、`assets`，需要后端时增加 `supabase`；条件项见 [记录契约](references/record-contract.md)。使用 [批量探测脚本](scripts/probe-suite.sh) 并行留证；真实 URL 的内容、MIME、版本与浏览器验收仍需核对。已有产物重复发布目标 ≤5 分钟；首次候选目标 5–8 分钟（用户域名/备案等待另计），记录实际耗时，不能为达标跳过证据。

## 托管前提

先读取项目、会话及已有环境记录；更新/回退沿用已核实的桶、入口域名与托管路线。既有记录属于非 OBS 托管时，保留历史并说明超出本 skill 范围，不改标为 OBS 或自动迁移资源。

托管配置读 [域名与托管](references/hosting.md)，入口域名与探测读 [入口域名、证书与入口探测](references/domain-provisioning.md)，发布、更新或回退读 [OBS 发布](references/obs-release.md)。缺少可用域名或适用备案时，在已确定的构建环境中准备产物、运行可用预览，并可按明确授权上传候选，列出上线清单；不报告公网完成，也不改用存储服务默认域名。

## 任务与工作流

1. **确定范围。** 区分环境检查、安装/准备构建环境、创建并部署、只接入 Supabase、更新、回退及环境/服务维护。只接入后端不隐含采购资源；仅有访问 URL 而无源码/发布权限时完成只读诊断并列出缺项，不宣称已改造应用。
2. **识别应用与静态边界。** 创建/修改应用时读 [前端构建](references/frameworks.md)，先确认源码、框架、实际路由及产物能否独立静态服务。新项目未指定时使用 React＋Vite＋TypeScript；Vue、普通静态网站和已有静态导出沿用原方案。需要路径级改写、负向路径 4xx 或加速层缓存的站点必须选 `obs-cdn`；其余默认 `obs-domain`。SSR、服务端 API、运行时秘密需求单独说明；本 skill 不部署后端。
3. **确定并核实构建环境。** 构建、工具缺失或维护时读 [构建环境](references/build-environment.md)，先确定产物来源或构建位置，再按项目约束检查该环境的 Node 与包管理器。优先复用已有构建产物或 CI；本地构建复用兼容的现有工具，版本不匹配时不自动安装、升级或切换本地 Node。OBS 仅接收静态产物。仅在查询/管理华为云资源时读 [认证](references/authentication.md) 和 [区域](references/regions.md)，核实账号归属、资源、部署权限、费用和已有记录。首次永久 AK/SK 默认通过已核实版本 DevKit 一次终端初始化；已有认证直接复用。OBS 项目已有 Supabase HTTPS URL/公开 Key，且本次仅检查后端接入时，不强制新增华为云 CLI 认证。
4. **接入已有 Supabase。** 需要后端时读 [Supabase](references/supabase.md)，配置公开连接参数、真实 origin、回调、CORS 和 RLS。使用已核实的实际稳定入口配置回调；域名尚未就绪时先准备产物与本地预览，最终地址确定后更新配置并重新构建。没有安全可用的后端地址时，不扩张网络权限来掩盖缺项。
5. **构建、发布并建立入口。** 发布、续跑或回退前读 [OBS 发布记录与验收](references/deployment.md) 和 [记录契约](references/record-contract.md)，在状态变化时写入环境、版本与检查事件。准备本次请求、资源/配置差异、费用和恢复点，在已有授权内执行；域名、证书、DNS 记录与路线选择并进一次性确认清单，确认后全程自动，不再逐项打断。快速路径沿用本次已有授权；其余生产入口切换以及共享 DNS/CDN 修改，先展示本次差异、影响范围和恢复点并取得确认；新付费资源及授权外公网/数据库变更另行确认。首次登录、MFA、域名实名及备案由用户完成。仅检查或资源准备计划请求保持只读；部署请求本身不授权修改本地 Node/包管理器。
6. **探测、验证与交付。** 先派生并创建入口域名、写 DNS、配证书，再 `GET` 入口根路径做一次探测：通过则返回链接与证据，失败按 [失败原因枚举](references/domain-provisioning.md#失败原因枚举) 归类并给出下一步，不撤销已建资源。探测通过只表示入口可访问；继续按第 5 步的验收规则校验产物、资源、路由与后端，只有全部必需检查通过才记录成功版本；缺项、诊断通过或全 N/A 均不能作为线上验收通过。

## 工具与边界

独立只读检查单批并行；连通探测从 `--max-time 5` 开始，实际大对象按大小调整。认证/权限错误不重试。内部云使用 OBS 分支；其他华为云资源优先 KooCLI，OBS 文件默认用 KooCLI 内置 `hcloud obs`，兼容已有独立 obsutil；构建复用已有 CI 或已确定的本地/容器环境。执行前核对本地帮助和当前官方 schema；工具缺失按对应构建/托管指引在授权内准备；安装受阻时说明缺口，不自建签名器或调用未公开接口。自定义域名与证书绑定能否仅靠 CLI 完成尚未核实，不能自动化时输出控制台步骤，不假装已完成。

查询分页完成才判定资源不存在。认证/权限/参数错误修正前停止重试；瞬时读取最多重试三次。异步创建或发布结果不明先查询任务及资源，不能盲目重复购买或发布；等待默认最多 30 分钟，超时记录域名、记录、证书与任务 ID 供续跑。保留共享配置，不因缺域名、无配额或区域限制自动更换资源区域或购买数据库。

## 交付

报告构建环境与托管路线配置、实际工具版本/镜像摘要、修改、产物、入口域名与实际访问 URL（注明协议、预览/生产）、当前及前一成功版本、探测结果与失败原因、验收与恢复结果、费用假设和阻碍。明确区分 **本地应用已验证**（实际应用通过本地构建与适用检查）、**环境已准备**（工具、资源和权限已核实，入口待验项单列）、**线上验收通过**（真实入口全部适用检查通过）；HTTP 入口可达不等于 HTTPS 通过，也不等于 Supabase 登录通过——非安全上下文下 PKCE 登录可能不可用，补齐证书后复验。官方依据与运行限制随各操作指引提供；本地检查和用户报告不能代替目标账号及应用的实际验证。

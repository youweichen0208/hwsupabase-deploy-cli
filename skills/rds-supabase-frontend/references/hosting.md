# 域名、存储与托管路线

## 入口前置条件

用户使用 `https://www.example.com` 这类自有域名访问前端，浏览器另行访问 Supabase HTTPS API。用户登录应用使用 Supabase Auth，无需华为云账号。

先读取已有域名、证书、桶和托管记录，查询所有权、配置与状态。没有域名时交付本地预览、构建产物和上线清单；存储服务默认域名可能强制下载网页文件，不能充当稳定入口。

域名注册、实名认证及备案由用户完成，不代替用户作身份声明。中国大陆区域绑定自有域名需域名已备案，首次通过华为云备案还涉及可备案资源条件，按当前官方规则检查；不能承诺仅买域名即可上线或没有其他资源成本。不因备案缺项自动购买服务器、改到境外或改用默认域名。

入口域名的派生、绑定、DNS 与证书顺序见 [入口域名、证书与入口探测](domain-provisioning.md)。

依据：[OBS 在线预览约束](https://support.huaweicloud.com/usermanual-obs/obs_03_0342.html)、[备案条件](https://support.huaweicloud.com/icprb-icp/icp_01_0008.html)。

## 托管路线

只有两条，按环境显式记录在 `hosting_kind`：

| 路线 | 接法 | 能力 |
| --- | --- | --- |
| `obs-domain`（默认） | 入口域名直连存储桶 | 便宜、无缓存层、无路径改写、无加速层证书；依赖静态网站托管 |
| `obs-cdn` | 入口域名经加速层回源同一公开桶 | 缓存、路径改写、负向路径 4xx、证书在加速层终止 |

默认 `obs-domain`。出现下列任一需求时改用 `obs-cdn`，并在确认清单中说明原因：

- 需要路径级改写（例如 `/login`、`/auth/callback` 内部改写到入口，而不是全局回落首页）。
- 需要缺失资源与未知路径返回 4xx，正文不是首页。
- 需要加速层缓存控制、缓存刷新，或按 URL 预热。
- 需要加速层证书终止或 HTTPS 强制跳转等入口能力。

两条路线都不需要私有桶与回源委托：前端产物本来就是公开内容，桶对匿名读开放。

## 桶与公开读

1. 优先复用本项目专用前端桶；新桶明确 region、名称、存储类别、企业项目和保留策略。不混用 Supabase 用户上传文件桶。
2. 本项目专用公开前端桶的策略以 `bucket/*` 通配允许匿名 `GetObject`，不按版本逐项列白名单。共享或含非公开内容的桶不得自动扩大范围；先明确授权与隔离。写权限、`PutObject`、列举权限不开放给匿名身份。
3. 开启匿名读后，桶内不得存放秘密、备份、配置快照或用户数据；这些文件放在 web root 之外的私有位置。
4. 查询失败不作为创建理由；分页查询完成才判定资源不存在。

## 静态网站托管的边界

`obs-domain` 依赖静态网站托管，只有两项能力：

- index document：`/` 与目录式路径返回入口 HTML。
- error document：未命中对象时返回入口 HTML。

因此 `obs-domain` 下**没有路径级路由**：配不出 `/login → 入口 HTML` 这类规则，只能全局回落；缺失资源也返回首页，负向路径无法用 4xx 判别。需要这些能力时按 [托管路线](#托管路线) 升级到 `obs-cdn`。

## 资源计划与配置顺序

1. 确认路线（默认 `obs-domain`），列出本次差异、影响范围、恢复点与费用，进入一次性确认清单。
2. 查询优先：域名绑定、静态网站托管状态、桶策略、DNS 记录、证书是否已存在；存在则复用并核对差异。
3. 创建或复用桶，设置匿名读策略。
4. 上传产物并校验；首次空桶只上传已获发布授权的版本化候选，见 [发布顺序](obs-release.md#发布顺序)。
5. `obs-domain`：开启静态网站托管并配置 index 与 error document；`obs-cdn`：配置加速域名、源站与改写规则。
6. 绑定入口域名并写入 DNS，见 [入口域名、证书与入口探测](domain-provisioning.md)。
7. 探测入口；通过后按 [真实验收](deployment.md#真实验收) 继续其余项目，或补 HTTPS 后复验。

管理操作优先 `hcloud obs --help`、`hcloud CDN --help`、`hcloud DNS --help` 发现命令；请求 schema 从当前命令帮助或 API Explorer 取得，不自行猜测字段。含证书私钥等秘密的请求文件使用临时受限文件，不纳入版本记录。

## 缓存与版本

对象用内容哈希或版本路径保持不可变，响应头按内容区分：不可变资源长缓存，HTML 与其他可变文件短缓存或不缓存。`obs-domain` 不经过加速层，缓存由对象元数据与浏览器决定；`obs-cdn` 另有加速层缓存，切换入口后必须按实际缓存键刷新再验收。

## 预算与告警

优先使用用户或项目已明确的预算；未提供时列出费用估算、用量假设和未知项。按当前站点价格及查询日期核算存储容量、请求数、回源与下行流量、域名年费折月、证书或 DNS 的适用费用，并区分两条路线的差异（加速层流量与请求费只在 `obs-cdn` 产生）。价格未知时明确未知，不给出虚构报价。

Supabase 实例、存储、公网带宽及其他后端费用独立列出。已有授权且产品支持时设置费用预算告警与流量告警，记录无法配置的告警及人工路径。预算与告警不是账单硬上限。

依据：[OBS 静态网站托管](https://support.huaweicloud.com/usermanual-obs/obs_03_0352.html)、[CDN 配置入口](https://support.huaweicloud.com/usermanual-cdn/cdn_01_0001.html)。

### 专用公开桶策略模板

按当前 OBS 帮助核对 schema 后替换桶名，保留已有必要策略；模板只授对象读取，不授 ListBucket。部署不重复做 `anonymous_list_closed` 验收；策略变更时审查完整策略及 ACL，不能靠此模板推断其他授权不存在。

```json
{"Statement":[{"Effect":"Allow","Principal":{"ID":["*"]},"Action":["GetObject"],"Resource":["example-frontend/*"]}]}
```

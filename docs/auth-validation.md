# 统一认证入口验证记录

本记录验证 skill 的接入指引，不代表客户账号认证、OBS 上传或生产部署成功。与既有 [环境验证](environment-validation.md) 分开记录。

## 固定版本和隔离方式

- npm 官方发布包：`huaweicloud-devkit@1.1.13`；通过 npm 元数据确认版本、来源及 Node ≥22 声明，校验发布 tarball 的 SHA-512 与 npm dist.integrity 一致，检查实际发布包中的初始化代码，不以仓库 main 代替发布版本。
- 运行环境：Docker `node:22-bookworm-slim`，实际 Node 22.23.3。测试容器使用自身用户目录，网络关闭；仅只读挂载下载到临时目录的官方包和测试文件，未挂载客户凭证或项目源码。
- KooCLI 配置/身份请求的行为测试使用容器内的模拟命令；虚构 AK/SK/Token 只用于测试。另运行真实 PTY 输入流程验证 SK 不回显。
- 另下载官方 KooCLI 7.3.12 Linux arm64 发行包，在无网络容器内核对 `hcloud version`、`hcloud obs help cp`（vmd5/meta）和 `hcloud obs help ls`。首次帮助查询被隐私交互阻止；仅在测试容器接受后复测通过。未传入真实凭证。
- 未安装 DevKit 插件，未修改本机 Node、KooCLI、OBS 或真实凭证配置。

## 执行结果

| 检查 | 结果与范围 |
| --- | --- |
| CLI 帮助 | `--help` 确认 auth init/sync/status/reconcile 和 install-hcloud 入口 |
| 非交互且没有凭证 | 退出码 1，未生成 OBS 配置，不假装完成初始化 |
| 首次真实终端交互 | 依次输入虚构 AK、SK、空 Token；SK 不回显；设置的区域用于 OBS Endpoint |
| 缺少 KooCLI | 凭证库与 OBS 配置已写入，程序可返回 0；因此不能以退出码判断完整就绪 |
| 永久凭证正常流程 | 模拟 KooCLI 收到配置操作及 STS 身份查询；成功输出同步完成，不代表真实 API 成功 |
| 身份校验失败 | 模拟 Unauthorized，退出码 1且不输出同步成功 |
| 临时凭证 | Token 进入 OBS/凭证库，但未传给 KooCLI configure；简化入口明确排除此模式 |
| 已有加密 profile / OBS 配置 | 模拟当前 customer profile 收到删除请求，默认 OBS 文件被替换；原流程须先保护配置，不能当无损同步 |
| 本地文件与输出 | 容器内 OBS 文件权限 0600；最终非交互输出不含虚构 AK/SK；不代表内部进程参数不可见 |
| 工具安装网络失败 | 网络关闭且容器无 curl 时 install-hcloud 下载失败并输出手动指引；没有安装成功证据，不报告工具已准备 |

发布包还显示：未提供区域时默认北京四；已有 HW_* 环境变量可跳过交互；永久凭证初始化会重建当前 profile；初始化会尝试 IAM 项目发现。故指引要求显式区域、确认注入身份、保护已有配置，并以本次所需服务的实际查询判断权限。IAM 项目查询失败不能单独证明 OBS 不可用。

## 场景推演（非真实云测试）

- 已有两端有效配置：跳过统一初始化，直接执行本次服务预检。
- 多账号或共享 OBS 配置：列出实际影响，保护原配置，仅在迁移授权覆盖时执行；否则沿用原方式。
- Node 缺失/不兼容：报告 DevKit 运行条件，不自动安装或切换，不改变前端构建版本。
- SSO、AssumeRole、ECS 委托：保留专用认证；不复制源身份的密钥冒充最终身份。
- 临时令牌遗漏/过期：沿用临时认证流程，完整核实 AK/SK/Token；不要求删令牌重试。
- OBS 403：分别判断目标桶权限、账号与策略；全局列桶失败不作为目标桶失败的充分证据。
- 网络/TLS 失败：报告连接阶段，保持 TLS 校验和原配置，不反复初始化。
- 部分写入或初始化中断：核对实际写入范围，恢复受影响快照；不连续重跑覆盖。

真实云端需继续验收：目标账号身份、实际区域、所需 API 权限、目标桶访问及授权范围内的上传。未执行登录、真实凭证初始化、云资源变更或前端发布。

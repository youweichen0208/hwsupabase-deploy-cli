# 调研记录：华为云 RDS Supabase 应用交付

日期：2026-11-06。范围经过确认：交付团队使用；静态前端 + Flask/Django；连接已有华为云 RDS Supabase；前端公网直连、后端内网；Storage 接入为可选；要求重复部署、续跑与回退。

关键选择是复用官方服务 Skills/KooCLI，增加客户交付状态和应用适配。官方 DevKit 的通用 IaC 流程使用会话状态，不能直接满足跨会话交付；本实现保持自身持久状态，不复制官方 API 实现。

第一手依据和每条能力对应影响集中维护在 [官方依据](../skills/hw-supabase-deliver/references/sources.md)。官方主分支源码只是能力证据，不能宣称已在所有区域发布。当前实际运行过的本地检查与仍需客户环境验证的项目见 [验证记录](validation.md)。

实施增加了两个确定性边界：OBS CLI 文本不能可靠区分“不存在”和“权限不足”，因此只读探针使用官方 OBS SDK；创建发生超时后，只有云端精确回查成功才会恢复检查点，否则停止自动重试，避免重复购买资源。

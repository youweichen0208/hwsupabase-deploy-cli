# 域名不代注册、不代备案，只派生已有主域名下的子域

本 skill 可以自动创建入口所需的域名资源，但域名本身必须由用户提供并已具备上线条件：agent 只在用户给出的已备案主域名下派生入口子域，不注册新域名、不代用户完成实名认证或备案，也不因缺少域名而更换区域或采购备案资源。

## Considered Options

- **自动注册新域名并代办备案**：注册、实名认证与备案都是异步的、要求主体本人声明身份，以天或周计，会让"一键部署"变成一个多日流程，并让 agent 替用户作出身份声明。
- **退化到存储服务默认域名**：默认域名可能强制下载页面文件，不能充当稳定入口，见 `skills/huawei-supabase-frontend/references/hosting.md`。

## Consequences

域名缺失或未完成备案时，本次交付停在"环境已准备"：保留产物与预览，列出上线清单，不报告线上完成。

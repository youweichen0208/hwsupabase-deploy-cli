# 放弃私有回源，改用公开读桶，并保留两条托管路线

存储桶对匿名读开放，加速层不再持委托凭证回源，原先的私有回源与 `CDNAccessPrivateOBS` 委托整体删除。新增 `obs-domain`（入口域名直连桶）与 `obs-cdn`（入口域名经加速层回源公开桶）两条托管路线，默认 `obs-domain`，能力不足时升级到 `obs-cdn`。

## Considered Options

- **继续私有回源**：安全表述更好，但需要委托、回源鉴权与"匿名直连不可读"的验收，云上配置面更大；客户实际要的是"加个域名就能访问"。
- **全部走加速层**：能力最全（缓存、路径改写、证书终止），但每次部署都引入缓存与刷新语义，成本与故障面更高。

## Consequences

- 前端产物本来即为公开内容，私有回源保护的是桶而不是页面；`obs-domain` 下匿名直连可读是预期行为，不再是缺陷。
- `obs-domain` 依赖存储侧的静态网站托管与错误文档回落首页，因此缺失资源与未知路径不再返回 4xx，"负面路径"验收项只对 `obs-cdn` 适用。
- 回退不再依赖刷新缓存：`obs-domain` 以覆盖入口文件完成切换，`obs-cdn` 仍需按缓存键刷新。
- 既有 2026-11-07 的两份验证记录针对旧路线，已删除；当前没有任何一条托管路线具备云端验证证据。
